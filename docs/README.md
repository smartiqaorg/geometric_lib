# Math formulas
## Area
- Circle: S = πR²
- Rectangle: S = ab
- Square: S = a²

## Perimeter
- Circle: P = 2πR
- Rectangle: P = 2a + 2b
- Square: P = 4a
## Running the examples with Python 3

The shape modules can be imported from the repository root:

```sh
python3 -c 'import circle; print(circle.area(2))'
python3 -c 'import square; print(square.perimeter(4))'
```

The `main` branch contains the circle and square modules. Additional examples
such as the interactive calculator are available in the `develop` branch.
