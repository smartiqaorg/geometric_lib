# Math formulas
## Area
- Circle: S = πR²
- Rectangle: S = ab
- Square: S = a²

## Perimeter
- Circle: P = 2πR
- Rectangle: P = 2a + 2b
- Square: P = 4a

## Usage

Run Python from the repository root to import the modules available on `main`:

```python
import circle
import square

print(circle.area(2))       # 12.566370614359172
print(circle.perimeter(2))  # 12.566370614359172
print(square.area(3))       # 9
print(square.perimeter(3))  # 12
```

Use the same unit for every input length. Areas are expressed in squared units;
perimeters use the original length unit.
