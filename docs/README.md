# Geometric Library

Небольшая библиотека на Python для вычисления площади и периметра геометрических фигур.

## Навигация

- [Описание функций](functions.md)
- [История изменений](history.md)

В проекте два модуля:
- `circle.py` — вычисление площади круга и длины окружности.
- `square.py` — вычисление площади и периметра квадрата.

## Math formulas

### Area
- Circle: S = πR²
- Square: S = a²

### Perimeter
- Circle: P = 2πR
- Square: P = 4a
