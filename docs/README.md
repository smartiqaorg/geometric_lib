## Общее описание

Проект **geometric_lib** содержит набор модулей на языке Python для работы с геометрическими фигурами:
*   Круг `circle.py`
*   Прямоугольник `rectangle.py`
*   Квадрат `square.py`
*   Треугольник `triangle.py`

Каждый модуль содержит две основные функции: `area()` для вычисления площади и `perimeter()` для вычисления периметра.

## Математические формулы

### Площадь
*   Круг: S = πR²
*   Прямоугольник: S = ab
*   Квадрат: S = a²
*   Треугольник: S = ½ah

### Периметр
*   Круг: P = 2πR
*   Прямоугольник: P = 2a + 2b
*   Квадрат: P = 4a
*   Треугольник: P = a + b + c

## Описание функций

### `circle.py`
*   **`area(r)`**
    *   *Описание:* Принимает радиус круга `r`, возвращает его площадь.
    *   *Пример вызова:*
        `area(3)` # Результат: 28.274333882308138
*   **`perimeter(r)`**
    *   *Описание:* Принимает радиус круга `r`, возвращает длину окружности.
    *   *Пример вызова:*
        `perimeter(3)` # Результат: 18.84955592153876

### `rectangle.py`
*   **`area(a, b)`**
    *   *Описание:* Принимает стороны прямоугольника `a` и `b`, возвращает его площадь.
    *   *Пример вызова:*
        `area(4, 5)` # Результат: 20
*   **`perimeter(a, b)`**
    *   *Описание:* Принимает стороны прямоугольника `a` и `b`, возвращает его периметр.
    *   *Пример вызова:*
        `perimeter(4, 5)` # Результат: 18

### `square.py`
*   **`area(a)`**
    *   *Описание:* Принимает сторону квадрата `a`, возвращает его площадь.
    *   *Пример вызова:*
        `area(4)` # Результат: 16
*   **`perimeter(a)`**
    *   *Описание:* Принимает сторону квадрата `a`, возвращает его периметр.
    *   *Пример вызова:*
        `perimeter(4)` # Результат: 16

### `triangle.py`
*   **`area(a, h)`**
    *   *Описание:* Принимает основание `a` и высоту `h`, возвращает площадь треугольника.
    *   *Пример вызова:*
        `area(4, 5)` # Результат: 10.0
*   **`perimeter(a, b, c)`**
    *   *Описание:* Принимает три стороны треугольника `a`, `b`, `c`, возвращает его периметр.
    *   *Пример вызова:*
        `perimeter(3, 4, 5)` # Результат: 12
