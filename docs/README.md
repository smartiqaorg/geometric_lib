# Math formulas
## Area
- Circle: S = πR²
- Rectangle: S = ab
- Square: S = a²

## Perimeter
- Circle: P = 2πR
- Rectangle: P = 2a + 2b
- Square: P = 4a

## Project information

This repository contains a Python library for calculating
the area and perimeter of geometric shapes.

The project is used for practicing Git and GitHub.
