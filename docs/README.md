# Math formulas
## Area
- Circle: S = πR²
- Rectangle: S = ab
- Square: S = a²

## Perimeter
- Circle: P = 2πR
- Rectangle: P = 2a + 2b
- Square: P = 4a

## Quick example

```python
import circle
import square

print(circle.area(3))       # approximately 28.2743
print(square.perimeter(4))  # 16
```
