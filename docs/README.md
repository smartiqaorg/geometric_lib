# Math formulas
## Area
- Circle: S = πR²
- Rectangle: S = ab
- Square: S = a²

## Perimeter
- Circle: P = 2πR
- Rectangle: P = 2a + 2b
- Square: P = 4a

## Usage examples for Circle and Square

Run these examples from the repository root with Python 3:

```python
import circle
import square

print(circle.area(2))       # 12.566370614359172
print(circle.perimeter(2))  # 12.566370614359172
print(square.area(3))       # 9
print(square.perimeter(3))  # 12
```

The `main` branch contains the `circle` and `square` modules. The calculator
script and triangle module are available on `develop`; the rectangle module
is available on `feature`.
