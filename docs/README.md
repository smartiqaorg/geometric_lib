# Math formulas
## Area
- Circle: S = πR²
- Rectangle: S = ab
- Square: S = a²

## Perimeter
- Circle: P = 2πR
- Rectangle: P = 2a + 2b
- Square: P = 4a

## Repository structure
- `circle.py` - area and perimeter of a circle
- `square.py` - area and perimeter of a square
- `docs/README.md` - this documentation

## Usage example
```python
import circle, square
print(circle.area(1))     # 3.141592653589793
print(square.perimeter(2))  # 8
```
