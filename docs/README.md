## Общее описание решения

В проекте созданы несколько файлов для работы с геометрическими фигурами и математические инструменты.

- `circle.py`  площадь и длина окружности круга
- `rectangle.py` площадь, периметр и диагональ прямоугольника
- `square.py` площадь и периметр квадрата
- `triangle.py` проверка существования треугольника, его площадь и периметр
- `mathutils.py` базовые мат. функции

Каждая функция принимает числовые аргументы и возвращает число или `bool` в случае проверок. Внешних зависимостей нет.
## Описание функций
### circle.py
**`area(r)`** площадь круга радиуса `r`.
```
area(2) = 12.566...
```
**`perimeter(r)`** длина окружности радиуса `r`.
```
perimeter(3) = 18.85...
```
### rectangle.py
**`area(a, b)`** площадь прямоугольника со сторонами `a` и `b`.
```
area(2, 4) = 8
```
**`perimeter(a, b)`** периметр прямоугольника.
```
perimeter(2, 4) = 12
```
**`diag(a, b)`** длина диагонали прямоугольника.
```
diag(3, 4) = 5.0
```
### square.py
**`area(a)`** площадь квадрата со стороной `a`.
```
area(3) = 9
```
**`perimeter(a)`** = периметр квадрата.
```
perimeter(3) = 12
```
### triangle.py
**`is_triangle(a, b, c)`** проверяет, существует ли треугольник с такими сторонами (неравенство треугольника).
```
is_triangle(3, 4, 5) = True
```
**`area(a, b, c)`** площадь треугольника по формуле Герона. Возвращает `0`, если треугольник не существует.
```
area(3, 4, 5) = 6.0
```
**`perimiter(a, b, c)`** периметр треугольника.
```
perimiter(3, 4, 5) = 12
```
### mathutils.py
**`gcd(a, b)`** наибольший общий делитель (алгоритм Евклида).
```
gcd(12, 18) = 6
```
**`lcm(a, b)`** наименьшее общее кратное.
```
lcm(4, 6) = 12
```
**`factorial(n)`** факториал числа `n`.
```
factorial(5) = 120
```
**`is_prime(n)`** проверка числа на простоту.
```
is_prime(7) = True
```
