# Geometric Lib (Геометрическая библиотека)

Набор Python-модулей для быстрого вычисления площадей и периметров базовых геометрических фигур: круга, прямоугольника, квадрата и треугольника.

## Общее описание решения

Проект представляет собой библиотеку математических функций, сгруппированных по типам геометрических фигур. Каждый модуль отвечает за конкретную фигуру и предоставляет стандартный интерфейс для расчёта двух основных характеристик:

* **Площадь (`area`)**
* **Периметр (`perimeter`)**

Все модули используются как подключаемые библиотеки в сторонних Python-проектах.

## Описание функций с примерами вызова

### 1. Модуль `circle.py` (Круг)

Модуль использует константу `math.pi` для точных вычислений.

#### `area(r)`

Вычисляет площадь круга радиуса `r`.

* **Параметры:** `r` (`int` или `float`) — радиус круга.
* **Возвращаемое значение:** (`float`) — площадь круга ($S = \pi r^2$).
* **Пример вызова:**

  ```python
  import circle

  r = 5
  res = circle.area(r)
  print(f"Площадь круга с радиусом {r}: {res}")
  # Вывод: Площадь круга с радиусом 5: 78.53981633974483
  ```

#### `perimeter(r)`

Вычисляет длину окружности (периметр) круга радиуса `r`.

* **Параметры:** `r` (`int` или `float`) — радиус круга.
* **Возвращаемое значение:** (`float`) — длина окружности ($P = 2\pi r$).
* **Пример вызова:**

  ```python
  import circle

  r = 5
  res = circle.perimeter(r)
  print(f"Периметр круга с радиусом {r}: {res}")
  # Вывод: Периметр круга с радиусом 5: 31.41592653589793
  ```

### 2. Модуль `rectangle.py` (Прямоугольник)

#### `area(a, b)`

Вычисляет площадь прямоугольника со сторонами `a` и `b`.

* **Параметры:**
  * `a` (`int` или `float`) — длина первой стороны.
  * `b` (`int` или `float`) — длина второй стороны.
* **Возвращаемое значение:** (`int` или `float`) — площадь прямоугольника ($S = a \cdot b$).
* **Пример вызова:**

  ```python
  import rectangle

  a, b = 10, 4
  res = rectangle.area(a, b)
  print(f"Площадь прямоугольника {a}x{b}: {res}")
  # Вывод: Площадь прямоугольника 10x4: 40
  ```

#### `perimeter(a, b)`

Вычисляет периметр прямоугольника со сторонами `a` и `b`.

* **Параметры:**
  * `a` (`int` или `float`) — длина первой стороны.
  * `b` (`int` или `float`) — длина второй стороны.
* **Возвращаемое значение:** (`int` или `float`) — периметр прямоугольника ($P = 2 \cdot (a + b)$).
* **Пример вызова:**

  ```python
  import rectangle

  a, b = 10, 4
  res = rectangle.perimeter(a, b)
  print(f"Периметр прямоугольника {a}x{b}: {res}")
  # Вывод: Периметр прямоугольника 10x4: 28
  ```

### 3. Модуль `square.py` (Квадрат)

#### `area(a)`

Вычисляет площадь квадрата со стороной `a`.

* **Параметры:** `a` (`int` или `float`) — длина стороны квадрата.
* **Возвращаемое значение:** (`int` или `float`) — площадь квадрата ($S = a^2$).
* **Пример вызова:**

  ```python
  import square

  a = 6
  res = square.area(a)
  print(f"Площадь квадрата со стороной {a}: {res}")
  # Вывод: Площадь квадрата со стороной 6: 36
  ```

#### `perimeter(a)`

Вычисляет периметр квадрата со стороной `a`.

* **Параметры:** `a` (`int` или `float`) — длина стороны квадрата.
* **Возвращаемое значение:** (`int` или `float`) — периметр квадрата ($P = 4 \cdot a$).
* **Пример вызова:**

  ```python
  import square

  a = 6
  res = square.perimeter(a)
  print(f"Периметр квадрата со стороной {a}: {res}")
  # Вывод: Периметр квадрата со стороной 6: 24
  ```

### 4. Модуль `triangle.py` (Треугольник)

#### `area(a, h)`

Вычисляет площадь треугольника по основанию `a` и высоте `h`.

* **Параметры:**
  * `a` (`int` или `float`) — длина основания.
  * `h` (`int` или `float`) — высота, опущенная на основание `a`.
* **Возвращаемое значение:** (`float`) — площадь треугольника ($S = \frac{a \cdot h}{2}$).
* **Пример вызова:**

  ```python
  import triangle

  a, h = 8, 5
  res = triangle.area(a, h)
  print(f"Площадь треугольника (основание={a}, высота={h}): {res}")
  # Вывод: Площадь треугольника (основание=8, высота=5): 20.0
  ```

#### `perimeter(a, b, c)`

Вычисляет периметр треугольника по трём его сторонам `a`, `b`, `c`.

* **Параметры:**
  * `a` (`int` или `float`) — первая сторона.
  * `b` (`int` или `float`) — вторая сторона.
  * `c` (`int` или `float`) — третья сторона.
* **Возвращаемое значение:** (`int` или `float`) — периметр треугольника ($P = a + b + c$).
* **Пример вызова:**

  ```python
  import triangle

  a, b, c = 3, 4, 5
  res = triangle.perimeter(a, b, c)
  print(f"Периметр треугольника со сторонами {a}, {b}, {c}: {res}")
  # Вывод: Периметр треугольника со сторонами 3, 4, 5: 12
  ```
