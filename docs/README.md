# Math formulas

## Файлы проекта

- `circle.py` — расчёт круга
- `rectangle.py` — расчёт прямоугольника
- `square.py` — расчёт квадрата
- `triangle.py` — расчёт треугольника

## Формулы

### Площадь (Area)

| Фигура | Формула |
|--------|---------|
| Круг | S = πR² |
| Прямоугольник | S = ab |
| Квадрат | S = a² |
| Треугольник | S = (a · h) / 2 |

### Периметр (Perimeter)

| Фигура | Формула |
|--------|---------|
| Круг | P = 2πR |
| Прямоугольник | P = 2a + 2b |
| Квадрат | P = 4a |
| Треугольник | P = a + b + c |
