# Документация проекта:Калькулятор площадей и периметров

## Общее описание решения
Данный проект представляет собой библиотеку для выполнения базовых геометрических расчетов. Он позволяет вычислять площадь и периметр четырех основных фигур: круга, квадрата, прямоугольника и треугольника.

## Описание функций с примерами вызова

### Прямоугольник (rectangle.py)
* **area(a, b)** — Вычисляет площадь прямоугольника по двум смежным сторонам.
  * *Пример вызова:* `area(10, 5)` -> возвращает `50`
* **perimeter(a, b)** — Вычисляет периметр прямоугольника.
  * *Пример вызова:* `perimeter(10, 5)` -> возвращает `30`

### Треугольник (triangle.py)
* **area(a, h)** — Вычисляет площадь треугольника по стороне и проведенной к ней высоте.
  * *Пример вызова:* `area(6, 4)` -> возвращает `12.0`
* **perimeter(a, b, c)** — Вычисляет периметр треугольника по трем сторонам.
  * *Пример вызова:* `perimeter(3, 4, 5)` -> возвращает `12`

### Квадрат (square.py)
* **area(a)** — Вычисляет площадь квадрата по длине его стороны.
  * *Пример вызова:* `area(4)` -> возвращает `16`
* **perimeter(a)** — Вычисляет периметр квадрата.
  * *Пример вызова:* `perimeter(4)` -> возвращает `16`

### Круг (circle.py)
* **area(r)** — Вычисляет площадь круга по заданному радиусу.
  * *Пример вызова:* `area(3)` -> возвращает `28.274333882308138`
* **perimeter(r)** — Вычисляет длину окружности (периметр круга) по его радиусу.
  * *Пример вызова:* `perimeter(3)` -> возвращает `18.84955592153876`

### Прямоугольник (rectangle.py)
* **Исходный код программы:**

```python
def area(a, b):
    '''Принимает числа a и b, возвращает площадь.'''
    return a * b

def perimeter(a, b):
    '''Принимает числа a и b, возвращает периметр.'''
    return 2 * (a + b)
```
