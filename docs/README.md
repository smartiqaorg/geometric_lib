# Math formulas
## Area
- Circle: S = πR²
- Rectangle: S = ab
- Square: S = a²

## Perimeter
- Circle: P = 2πR
- Rectangle: P = 2a + 2b
- Square: P = 4a

## Python usage examples

Run Python 3 from the repository root:

```python
import circle
import square

print(circle.area(2))       # 4 * pi
print(square.perimeter(3))  # 12
```

The functions return numbers; importing a module does not print a result.
