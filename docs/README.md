# Math formulas
## Area
- Circle: S = πR²
- Rectangle: S = ab
- Square: S = a²

## Perimeter
- Circle: P = 2πR
- Rectangle: P = 2a + 2b
- Square: P = 4a
## Usage examples

The modules use Python 3 and its standard library. Run these commands from the repository root:

```console
python -c "import circle; print(circle.area(2))"
python -c "import square; print(square.perimeter(3))"
```

The circle example uses radius 2 and prints approximately 12.56637. The square example uses side length 3 and prints 12.
