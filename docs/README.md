# Документация проекта Geometric Lib

## Общее описание решения
Данный проект представляет собой библиотеку на Python для работы с геометрическими фигурами. Библиотека позволяет вычислять площади и периметры круга, квадрата, прямоугольника и треугольника.

## Описание функций с примерами вызова

### Окружность (circle.py)
* **area(r)**: Вычисляет площадь круга по радиусу R.
  * *Пример*: `area(3)` -> возвращает `28.27`
* **perimeter(r)**: Вычисляет длину окружности по радиусу R.
  * *Пример*: `perimeter(3)` -> возвращает `18.85`

### Квадрат (square.py)
* **area(a)**: Вычисляет площадь квадрата по стороне a.
  * *Пример*: `area(5)` -> возвращает `25`
* **perimeter(a)**: Вычисляет периметр квадрата по стороне a.
  * *Пример*: `perimeter(4)` -> возвращает `16`

### Прямоугольник (rectangle.py)
* **area(a, b)**: Вычисляет площадь прямоугольника по двум сторонам.
  * *Пример*: `area(3, 4)` -> возвращает `12`
* **perimeter(a, b)**: Вычисляет периметр прямоугольника.
  * *Пример*: `perimeter(3, 4)` -> возвращает `14`

### Треугольник (triangle.py)
* **area(a, h)**: Вычисляет площадь треугольника по основанию и высоте.
  * *Пример*: `area(3, 4)` -> возвращает `6.0`
* **perimeter(a, b, c)**: Вычисляет периметр треугольника по трем сторонам.
  * *Пример*: `perimeter(3, 4, 5)` -> возвращает `12`
