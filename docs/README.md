# Math formulas
## Area
- Circle: S = πR²
- Rectangle: S = ab
- Square: S = a²

## Perimeter
- Circle: P = 2πR
- Rectangle: P = 2a + 2b
- Square: P = 4a

## Usage examples

The geometric library provides functions for calculating
the area and perimeter of circles and squares.

import circle
import square

print(circle.area(3))
print(circle.perimeter(3))

print(square.area(4))
print(square.perimeter(4))
