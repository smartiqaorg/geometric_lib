# geometric_lib
## Описание решения

`geometric_lib` — небольшая библиотека на Python для вычисления площади, периметра и длины окружности. В текущей версии реализованы функции для квадрата, прямоугольника, треугольника и круга:

- `square.py` — площадь и периметр квадрата;
- `rectangle.py` — площадь и периметр прямоугольника.
- `circle.py` — площадь круга и длина окружности.
- `triangle.py` — площадь и периметр треугольника.

Функции возвращают вычисленное числовое значение. Для использования достаточно импортировать нужную функцию из соответствующего модуля.

Пример запуска:

```
python
from geometric_lib.square import area, perimeter

print(area(5))       # 25
print(perimeter(5))  # 20
```

## Описание функций и примеры вызова
### `square.area(a)`

Возвращает площадь квадрата со стороной `a` по формуле `S = a * a`.

```
python
from geometric_lib.square import area

print(area(5))  # 25
```

### `square.perimeter(a)`

Возвращает периметр квадрата со стороной `a` по формуле `P = 4 * a`.

```
python
from geometric_lib.square import perimeter

print(perimeter(5))  # 20
```

### `rectangle.area(a, b)`

Возвращает площадь прямоугольника с длиной `a` и шириной `b` по формуле `S = a * b`.

```
python
from geometric_lib.rectangle import area

print(area(6, 5))  # 30
```

### `rectangle.perimeter(a, b)`

Возвращает периметр длиной `a` и шириной `b` по формуле `P =  (a + b) * 2`.

```
python
from geometric_lib.rectangle import perimeter

print(perimeter(6, 5))  # 22
```

### `circle.area(r)`

Возвращает площадь радиуса `r` по формуле `S = п * r^2`.

```
python
from geometric_lib.circle import area

print(area(1))  # 3.1415
```

### `circle.perimeter(r)`

Возвращает длину окружности радиуса `r` по формуле `P = 2 * п * r`.

```
python
from geometric_lib.circle import perimeter

print(perimeter(1))  # 6.283
```

### `triangle.area(a, h)`

Возвращает площадь треугольника стороны `a` и высоты `h` по формуле `S = a * h / 2`.

```
python
from geometric_lib.triangle import area

print(area(6, 3))  # 9
```

### `triangle.perimeter(a, b, c)`

Возвращает периметр треугольника сторонами `a`, `b` и `c` по формуле `S = a + b + c`.

```
python
from geometric_lib.triangle import perimeter

print(perimeter(3, 4, 5))  # 12
```


# Математические формулы
## Плоащадь
- Circle: S = п * r^2
- Rectangle: S = a * b
- Square: S = a * a
- Triangle: S = a * h / 2

## Периметр
- Rectangle: P = (a + b) * 2
- Square: P = 4 * a
- Triangle: P = a + b + c

## Длина окружности
- Circle: P = 2 * п * r

## План тестирования

### 1. Цели и задачи тестирования
* **Цель:** Проверка корректности работы функций вычисления геометрических параметров фигур (площади и периметра).
* **Задачи:**
  * автоматизация проверки основных математических расчетов;
  * проверка поведения функций на стандартных и граничных входных данных;
  * предотвращение возникновения ошибок при дальнейшем изменении исходного кода.

### 2. Описание тестируемого продукта
Тестируемый продукт представляет собой набор модулей на языке Python для расчета площади и периметра геометрических фигур:
* `rectangle.py` — вычисление площади и периметра прямоугольника
* `square.py` — вычисление площади и периметра квадрата
* `circle.py` — вычисление площади и длины окружности круга
* `triangle.py` — вычисление площади и периметра треугольника

Требования к продукту: функции должны принимать числовые значения и возвращать точный результат в соответствии с математическими формулами.

### 3. Область тестирования
Тестированию подлежат следующие модули и функции:
* `rectangle.py`: функции `area(a, b)` и `perimeter(a, b)`
* `square.py`: функции `area(a)` и `perimeter(a)`
* `circle.py`: функции `area(r)` и `perimeter(r)`
* `triangle.py`: функции `area(a, h)` и `perimeter(a, b, c)`

### 4. Стратегия тестирования
* **Тип тестирования:** модульное (unit) функциональное тестирование.
* **Инструмент:** стандартная библиотека Python `unittest`.
* **Техники тест-дизайна:**
  * *эквивалентное разделение* — проверка типичных положительных целых чисел
  * *анализ граничных значений* — передача нулевых значений (`0`)

Тесты организованы в виде классов, унаследованных от `unittest.TestCase`, и расположены в директории `tests/`.

### 5. Критерии приемки
Тестирование считается успешно завершенным, если:
1. Выполнено **100%** запланированных тест-кейсов.
2. Все тесты завершаются со статусом **`OK`**.
3. В ходе выполнения отсутствуют ошибки сравнения (`AssertionError`) и необработанные исключения.

### 6. Ожидаемые результаты
По итогам тестов формируется консольный отчет c количеством выполненных проверок, временем выполнения и итоговым статусом (`OK` при успехе или `FAILED` с `Traceback`).

#### Запуск тестов
Для автоматического запуска всех модульных тестов из корневой директории проекта используется команда:
```bash
python3 -m unittest discover tests
```
