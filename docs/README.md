# Geometric Library

Небольшая библиотека на Python для вычисления площади и периметра геометрических фигур.

Проект состоит из четырёх модулей:
- `circle.py` — вычисления для круга.
- `square.py` — вычисления для квадрата.
- `rectangle.py` — вычисления для прямоугольника.
- `triangle.py` — вычисления для треугольника.

## Math formulas

### Area

- Circle: S = πR²
- Square: S = a²
- Rectangle: S = ab
- Triangle: S = ah / 2

### Perimeter

- Circle: P = 2πR
- Square: P = 4a
- Rectangle: P = 2(a + b)
- Triangle: P = a + b + c
