# План тестирования проекта geometric_lib

## 1. Цели и задачи тестирования 
**Цель:** Проверить корректность работы функций вычисления площади и периметра прямоугольника.
**Задачи:** 
- Проверить работу функций с положительными числами.
- Проверить граничные случаи (нули, отрицательные числа).
- Убедиться в отсутствии ошибок в математических формулах.

## 2. Описание тестируемого продукта
Библиотека `geometric_lib` на языке Python. В рамках тестирования проверяется модуль `rectangle.py`, содержащий функции `area(a, b)` и `perimeter(a, b)`. Требования: функции должны возвращать числовые значения, корректные по математическим формулам.

## 3. Область тестирования
В рамках данной работы тестируются модуль `rectangle.py`. Проверяются функции вычисления площади и периметра. Ввод данных пользователем не тестируется.

## 4. Стратегия тестирования
Используется **функциональное тестирование**. Применяется фреймворк `unittest`. Для функций написаны изолированные unit-тесты, проверяющие ожидаемые значения с помощью `assertEqual`.

## 5. Критерии приемки
Тестирование считается успешным, если все написанные unit-тесты завершаются со статусом `OK` (100% пройдено) без ошибок и исключений.

## 6. Ожидаемые результаты
- Успешное прохождение всех тестов в терминале.
- Отсутствие упавших тестов (Failures/Errors).
- Код тестов и план загружены в репозиторий GitHub.
