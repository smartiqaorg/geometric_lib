# Functions

В библиотеке реализованы функции для вычисления площади и периметра четырёх геометрических фигур.

## Circle

Файл [circle.py](../circle.py) содержит две функции.

### area(r)

Вычисляет площадь круга по заданному радиусу.

Параметры:
- `r` — радиус круга.

Возвращает площадь круга.

Пример:

```python
from circle import area

print(area(5))  # 78.53981633974483
```

### perimeter(r)

Вычисляет длину окружности по заданному радиусу.

Параметры:
- `r` — радиус окружности.

Возвращает длину окружности.

Пример:

```python
from circle import perimeter

print(perimeter(5))  # 31.41592653589793
```

## Square

Файл [square.py](../square.py) содержит две функции.

### area(a)

Вычисляет площадь квадрата по длине стороны.

Параметры:
- `a` — сторона квадрата.

Возвращает площадь квадрата.

Пример:

```python
from square import area

print(area(5))  # 25
```

### perimeter(a)

Вычисляет периметр квадрата по длине стороны.

Параметры:
- `a` — сторона квадрата.

Возвращает периметр квадрата.

Пример:

```python
from square import perimeter

print(perimeter(5))  # 20
```

## Rectangle

Файл [rectangle.py](../rectangle.py) содержит две функции.

### area(a, b)

Вычисляет площадь прямоугольника по длинам двух сторон.

Параметры:
- `a` — длина прямоугольника.
- `b` — ширина прямоугольника.

Возвращает площадь прямоугольника.

Пример:

```python
from rectangle import area

print(area(5, 10))  # 50
```

### perimeter(a, b)

Вычисляет периметр прямоугольника по длинам двух сторон.

Параметры:
- `a` — длина прямоугольника.
- `b` — ширина прямоугольника.

Возвращает периметр прямоугольника.

Пример после исправления формулы:

```python
from rectangle import perimeter

print(perimeter(5, 10))  # 30
```

## Triangle

Файл [triangle.py](../triangle.py) содержит две функции.

### area(a, h)

Вычисляет площадь треугольника по основанию и высоте.

Параметры:
- `a` — основание треугольника.
- `h` — высота треугольника.

Возвращает площадь треугольника.

Пример:

```python
from triangle import area

print(area(6, 4))  # 12.0
```

### perimeter(a, b, c)

Вычисляет периметр треугольника по длинам трёх сторон.

Параметры:
- `a` — первая сторона.
- `b` — вторая сторона.
- `c` — третья сторона.

Возвращает периметр треугольника.

Пример:

```python
from triangle import perimeter

print(perimeter(3, 4, 5))  # 12
```
