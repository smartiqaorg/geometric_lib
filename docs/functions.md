## circle.py

### `area(r)`

Возвращает площадь круга по радиусу.

```python
def area(r):
    '''
    Возвращает площадь круга.

    :param r: радиус круга (float)
    :return: площадь круга (float)

    Формула: S = π · r²

    Пример:
        >>> area(10.0)
        314.1592653589793
    '''
    return math.pi * r * r
```

**Параметры:**
- `r: float` — радиус круга.

**Возвращаемое значение:** `float` — площадь круга, `π · r²`.

**Сложность:** константная, O(1).

**Примечание:** результат всегда `float`, так как `math.pi` — число с плавающей точкой.

**Пример:**
```
area(10.0)   -> 314.1592653589793
area(5.0)    -> 78.53981633974483
area(2.5)    -> 19.634954084936208
```

### `perimeter(r)`

Возвращает длину окружности по радиусу.

```python
def perimeter(r):
    '''
    Возвращает длину окружности.

    :param r: радиус круга (float)
    :return: длина окружности (float)

    Формула: P = 2 · π · r

    Пример:
        >>> perimeter(10.0)
        62.83185307179586
    '''
    return 2 * math.pi * r
```

**Параметры:**
- `r: float` — радиус круга.

**Возвращаемое значение:** `float` — длина окружности, `2 · π · r`.

**Сложность:** константная, O(1).

**Примечание:** результат всегда `float`, так как `math.pi` — число с плавающей точкой.

**Пример:**
```
perimeter(10.0)   -> 62.83185307179586
perimeter(5.0)    -> 31.41592653589793
perimeter(2.5)    -> 15.707963267948966
```

## rectangle.py

### `area(a, b)`

Возвращает площадь прямоугольника по двум сторонам.

```python
def area(a, b):
    '''
    Возвращает площадь прямоугольника.

    :param a: первая сторона (float)
    :param b: вторая сторона (float)
    :return: площадь прямоугольника (float)

    Формула: S = a · b

    Пример:
        >>> area(10.0, 5.0)
        50.0
    '''
    return a * b
```

**Параметры:**
- `a: float` — первая сторона прямоугольника.
- `b: float` — вторая сторона прямоугольника.

**Возвращаемое значение:** `float` — площадь прямоугольника, `a · b`.

**Сложность:** константная, O(1).

**Пример:**
```
area(10.0, 5.0)   -> 50.0
area(13.0, 2.0)   -> 26.0
area(2.5, 4.0)    -> 10.0
```

Возвращает периметр прямоугольника по двум сторонам.

```python
def perimeter(a, b):
    '''
    Возвращает периметр прямоугольника.

    :param a: первая сторона (float)
    :param b: вторая сторона (float)

    Формула: P = 2 · (a + b)
```

- `b: float` — вторая сторона прямоугольника.

**Возвращаемое значение:** `float` — периметр прямоугольника, `2 · (a + b)`.

**Пример:**
```

perimeter(10.0, 5.0)   -> 30.0
perimeter(2.5, 4.0)    -> 13.0
```

## triangle.py

### `area(a, h)`

Возвращает площадь треугольника по стороне и высоте, опущенной на неё.

```python
def area(a, h):
    '''
    Возвращает площадь треугольника.

    :param a: сторона, к которой проведена высота (float)
    :param h: высота, опущенная на сторону a (float)
    :return: площадь треугольника (float)

    Формула: S = (a · h) / 2

    Пример:
        >>> area(10.0, 5.0)
        25.0
    '''
    return (a * h) / 2
```

**Параметры:**
- `a: float` — сторона треугольника, к которой проведена высота.
- `h: float` — высота, опущенная на сторону `a`.

**Возвращаемое значение:** `float` — площадь треугольника, `(a · h) / 2`.

**Сложность:** константная, O(1).

**Примечание:** результат всегда `float`, так как используется оператор деления `/`.

**Пример:**
```
area(10.0, 5.0)   -> 25.0
area(5.0, 20.0)   -> 50.0
area(3.0, 4.0)    -> 6.0
```

### `perimeter(a, b, c)`

Возвращает периметр треугольника по трём сторонам.

```python
def perimeter(a, b, c):
    '''
    Возвращает периметр треугольника.

    :param a: первая сторона (float)
    :param b: вторая сторона (float)
    :param c: третья сторона (float)
    :return: периметр треугольника (float)

    Формула: P = a + b + c

    Пример:
        >>> perimeter(3.0, 4.0, 5.0)
        12.0
    '''
    return a + b + c
```

**Параметры:**
- `a: float` — первая сторона треугольника.
- `b: float` — вторая сторона треугольника.
- `c: float` — третья сторона треугольника.

**Возвращаемое значение:** `float` — периметр треугольника, `a + b + c`.

**Сложность:** константная, O(1).

**Пример:**
```
perimeter(3.0, 4.0, 5.0)     -> 12.0
perimeter(12.0, 5.0, 13.0)   -> 30.0
perimeter(1.5, 2.0, 2.5)     -> 6.0
```
